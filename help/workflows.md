# 工作流与模板

工作流规定一个项目要经过哪些协作步骤。组织所有者和组织管理员可以维护原子任务与组织工作流模板。

## 原子任务、模板和项目任务流

| 名称       | 用途                               | 示例                         |
| ---------- | ---------------------------------- | ---------------------------- |
| 原子任务   | 定义一种工作，以及提交时填写的字段 | 翻译，需要填写译文并上传文件 |
| 工作流模板 | 把原子任务按阶段组合，供项目复用   | 翻译 → 校对 → 嵌字           |
| 项目任务流 | 项目创建时根据模板生成的具体流程   | 第一话的翻译、校对与嵌字     |

准备好原子任务，再编排模板，最后用模板创建项目。

## 定义原子任务

1. 进入顶部「管理」，打开原子任务管理。
2. 使用创建入口，填写名称和相关信息。
3. 配置提交字段，按需要选择单行文本、多行文本、数字、选择或文件。
4. 保存并确认原子任务已启用。

字段应写清楚成员要提交什么。例如翻译任务可以要求填写说明并上传译文，校对任务可以要求填写校对意见。

停用的原子任务不能再作为新步骤添加到模板。已有模板仍可使用它创建项目；需要停止新建项目使用某个流程时，请同时停用对应模板。

## 编排组织工作流模板

1. 在管理中的工作流模板页面创建模板，填写名称和说明。
2. 从原子任务列表添加步骤到画布。
3. 拖拽步骤调整先后顺序；把节点拖入另一个节点中心可以组成并行组，拖到左侧或列间可以插入阶段。
4. 选择节点，按需要调整名称、阶段与并行关系。
5. 检查流程后保存，并保持模板启用，以便创建项目时选择。

普通组员不能进入原子任务管理和组织模板编排。个人模板与组织模板分开维护，创建项目时以实际可选列表为准。

## 阶段与并行组

流程按阶段从前向后推进。一个阶段可以只有一个任务，也可以包含多个并行任务。

例如一个流程可以是：翻译 → 校对甲与校对乙并行 → 嵌字。两项校对全部完成后，嵌字才能提交。

后续阶段的任务可以提前接取，但提交仍需要前置阶段完成。流程支持线性阶段和并行组，不提供条件分支、循环或任意连线。

## 修改模板会影响哪些项目

**项目创建后拥有自己的工作流。** 修改模板的步骤、顺序和并行关系，不会改变已有项目的流程。

修改原子任务后，关联模板和以后新建的任务流使用最新定义；已有任务流保留创建时的任务名称和提交字段，图标会跟随原子任务更新。既有任务状态和历史提交不会因为编辑原子任务而改变。

因此，调整模板后，可以在下一次[创建项目](./projects.md#在企划下创建项目)时使用新流程。成员实际执行任务的方法见[接取与提交任务](./tasks.md)。
