**企划**承载作品资料，**项目**承载单次交付（例如一话/一章）的任务流。

## 1. 浏览与创建企划

在<a href="/dashboard/planning" target="_self">企划广场</a>可按关键词、类型与时间筛选作品；点击首个「**创建新企划**」卡片即可新建。

![企划广场：浏览全部作品、按类型筛选或创建新企划](/docs/screenshots/planning-plaza.webp)

- **封面与缩略图**：封面推荐 `2:3`，缩略图 `1:1`（可从封面直接裁剪），单张最大 `10MB`。
- **元信息标签**：支持手填或选用组织预制标签，选用后仍可自由改名改色。

## 2. 企划详情：项目、成员与附件

点击封面或「**查看企划**」进入详情页，可一站式查看作品简介、项目列表、参与成员统计和企划附件。

![企划详情页：展示作品概览、项目列表、成员完成数与附件](/docs/screenshots/project-detail.webp)

- **企划附件**：负责人可上传/删除，成员可在线预览或下载（普通文件 `≤ 50MB`，压缩包 `≤ 500MB`）。
- **成员统计**：完成数仅计入当前有效提交，被打回或重置的历史记录不计入。

## 3. 创建项目与推进进度

在企划详情中点击「**创建项目**」，填好名称并选择一个启用的工作流模板，系统会自动生成该项目的专属任务流。

点进具体项目后，左侧为可视化**流程进度与节点画布**，点击任意节点可在右侧查看**任务操作、附件预览与版本记录**：

![项目详情页：左侧展示阶段进度与流程画布，右侧展示选中任务详情、操作与版本记录](/docs/screenshots/project-progress.webp)

> **别忘了标记完成**：全部任务完成后，需由企划负责人或管理员点击右上角「**完成**」才算项目结项。若后续有任务被打回或重置，项目会自动回到进行中。

## 4. 删除规则

| 场景                                                | 删除方式                                                                    |
| :-------------------------------------------------- | :-------------------------------------------------------------------------- |
| 企划下无项目 / 项目无任何提交记录                   | 有权限者确认后直接删除                                                      |
| 企划已有项目 / 项目存在提交记录（含历史打回或重置） | 填写原因，提交组织管理员在[删除请求](/docs/organization#处理删除请求)中审核 |
