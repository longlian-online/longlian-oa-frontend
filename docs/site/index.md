白箱帮助汉化组把企划、项目和协作任务放在一起。组织配置工作流，组员接取、提交任务，按阶段推进项目。

## 第一次使用

先阅读[注册与加入组织](/docs/getting-started)，完成账号注册并进入组织。已有账号的成员，可以直接从[接取与提交任务](/docs/tasks)开始。

| 你想做什么                   | 从这里开始                              |
| ---------------------------- | --------------------------------------- |
| 注册账号、加入或切换组织     | [注册与加入组织](/docs/getting-started) |
| 找到任务、接取并提交成果     | [接取与提交任务](/docs/tasks)           |
| 查看作品、创建项目、确认完成 | [企划与项目](/docs/projects)            |
| 配置翻译、校对等协作步骤     | [工作流与模板](/docs/workflows)         |
| 邀请成员、审核申请、维护组织 | [管理组织](/docs/organization)          |
| 操作受限、任务等待或上传失败 | [常见问题](/docs/faq)                   |

## 先认识三个概念

**企划**是一个作品或协作主题的容器，例如某部漫画。**项目**是企划下的一次具体工作，例如第一话。**工作流**规定这个项目要经过哪些任务，例如翻译、校对、嵌字。

一个企划可以有多个项目，每个项目都有自己的任务流和进度。完成一个任务后，流程按组织配置的阶段继续推进。

## 按你的角色阅读

- **组员**：先学会[查找和处理任务](/docs/tasks)，再了解[企划与项目](/docs/projects)。
- **组织管理员、组织所有者**：先[配置工作流](/docs/workflows)，再[邀请成员并管理组织](/docs/organization)。

手册可以直接阅读，无需登录。实际业务操作需要登录，并具备当前组织中的相应权限。
