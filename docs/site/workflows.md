title: 工作流与模板
icon: Workflow
---

工作流决定一个项目要经过哪些协作步骤，由**组织所有者**和**组织管理员**在顶部「**管理**」中维护。

| 层级           | 作用                           | 示例                          |
| :------------- | :----------------------------- | :---------------------------- |
| **原子任务**   | 定义单个工种及提交表单字段     | 翻译（需上传译文 + 填写留言） |
| **工作流模板** | 把原子任务编排成可复用流程     | 翻译 → 校对 → 嵌字 → 发布     |
| **项目任务流** | 创建项目时按模板生成的独立流程 | 《银色的结晶》第一章任务流    |

## 1. 定义原子任务

进入「**管理 → 任务**」，创建并配置每个工种的名称、图标与提交字段（支持单行文本、多行文本、数字、单选与文件上传）。

![原子任务管理：维护组织内所有工种的定义、图标与启用状态](/docs/screenshots/base-tasks.webp)

> 停用原子任务后，新模板无法再选用它，但已有模板和项目不受影响。

## 2. 管理工作流模板

进入「**管理 → 工作流**」，可直观预览每条模板的阶段流转与并行人数（节点右下角 `+N` 表示并行槽位数），并支持搜索、禁用或进入编辑。

![工作流模板列表：卡片直观展示每条流程的步骤顺序、并行人数与任务总数](/docs/screenshots/workflows-list.webp)

## 3. 可视化编排画布

点击「**创建流程**」或卡片上的「**编辑**」即可进入画布编辑器：

![工作流画布编辑器：上方选择原子任务节点，下方拖拽编排串行阶段与并行组](/docs/screenshots/workflow-editor.webp)

- **添加步骤**：点击上方原子任务上的 `+`，或直接拖入下方画布。
- **串行与并行**：拖到列间可插入新阶段；**拖入已有节点中心**可组成并行组（同阶段所有并行任务全部完成后，才解锁下一阶段）。
- **检查启用**：保存后保持模板启用，新建项目时即可选用。

> **修改模板不影响已有项目**：每个项目在创建时都会复制一份独立流程；修改模板只对之后新建的项目生效。
