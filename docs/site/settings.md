登录后从右上角头像进入<a href="/dashboard/settings" target="_self">个人设置</a>，集中管理账号资料、安全、邮件通知、下载目录与 OpenAPI 密钥。

## 账号与安全

| 设置项       | 操作与规则                                                      |
| :----------- | :-------------------------------------------------------------- |
| **修改昵称** | 最多 20 字，不能为空，自动去除首尾空白                          |
| **更换头像** | 支持 JPG / PNG / GIF / AVIF，最大 `5MB`，支持在线裁剪           |
| **绑定邮箱** | 填入邮箱获取 6 位验证码（60 秒冷却），接收邮件通知前需先绑定    |
| **修改密码** | 6–20 位且同时包含大小写字母和数字；**修改后全部设备需重新登录** |

## 邮件通知

在「**通知**」卡片中调整提醒，所有开关**即时保存**且跨组织共用。关闭「邮件通知」总开关将停发所有邮件：

![邮件通知设置：总开关与六类协作提醒开关](/docs/screenshots/notification-settings.webp)

| 提醒类型            | 触发时机                                  |
| :------------------ | :---------------------------------------- |
| **可以开始**        | 你接取的任务已解锁、可以提交时            |
| **任务分配 / 打回** | 任务被分配给你，或提交成果被打回时        |
| **项目完成**        | 你创建的项目全部完成时                    |
| **入组 / 删除申请** | 有待审核申请时（仅发给组织管理员/所有者） |

## 存储设置与 OpenAPI 密钥

下方卡片按组织独立配置（切换顶部标签即可为不同组织设置）：

![存储设置与 OpenAPI 密钥：配置本地批量下载目录与管理开放接口密钥](/docs/screenshots/openapi-keys.webp)

- **存储设置**（仅管理员/所有者可见）：选择本地文件夹用于[组织文件批量下载](/docs/organization#查看与批量下载文件)（推荐使用桌面版 Chrome / Edge，按浏览器记住授权）。
- **OpenAPI 密钥**：用于脚本和外部工具[接入开放接口](/docs/openapi)。每组织最多 2 个有效密钥；**完整密钥仅创建时展示一次**，修改密码后全部密钥自动失效。
