登录后，打开[个人设置](/dashboard/settings)，可以更换头像、修改昵称和密码、绑定邮箱，以及配置邮件通知。组织所有者和组织管理员还可以为组织文件的批量下载选择本地存放位置。

## 修改个人资料

### 修改昵称

1. 在个人资料区点击「修改昵称」。
2. 填写新的昵称，点击「保存」。
3. 看到「昵称已更新」后，修改完成；点击「取消」则放弃本次编辑。

昵称是展示给其他成员的名字，不能为空或只包含空白，最多 20 个字符。保存时会去掉首尾空白。资料区同时显示账号的用户名和邮箱。

### 更换头像

1. 点击「更换头像」，选择图片。
2. 按裁剪窗口的提示调整并确认。
3. 等待上传和保存完成，看到「头像已更新」后再离开页面。

头像支持 JPG、JPEG、PNG、GIF 和 AVIF，最大 5MB。

## 绑定邮箱

邮箱显示「未绑定」时，可以点击旁边的「绑定」：

1. 填写要绑定的邮箱地址，点击「发送」。
2. 到该邮箱查收验证码，回到页面填写。
3. 点击「绑定邮箱」，看到「邮箱已绑定」后完成。

验证码为 6 位大写英文字母或数字，输入小写字母时会自动转为大写。发送后需等待 60 秒才能再次发送。已有绑定邮箱的账号会直接显示邮箱地址。

## 修改密码

1. 在「修改密码」区域点击「修改」。
2. 填写原密码和新密码。
3. 点击「保存」。

新密码必须为 6–20 位，并同时包含大写字母、小写字母和数字。

**修改成功后，全部设备都需要重新登录。** 当前页面会返回登录页，使用新密码登录即可继续操作。忘记原密码时，可以使用[找回密码](/forgot-password)。

## 配置邮件通知

在「通知」区域调整邮件提醒。每个开关修改后单独保存，无需再点击保存按钮。通知偏好跟随当前账号，在不同组织间共用。

「邮件通知」是总开关，关闭后所有类型都不再发送邮件。需要保留部分提醒时，打开总开关，再分别调整下面的类型：

| 类型     | 何时提醒                           |
| -------- | ---------------------------------- |
| 可以开始 | 你接取的任务可以提交时             |
| 任务分配 | 有任务分配给你时                   |
| 任务打回 | 你提交的任务被打回时               |
| 项目完成 | 你创建的项目全部完成时             |
| 入组申请 | 有入组申请时，仅向组织管理人员发送 |
| 删除申请 | 有删除申请时，仅向组织管理人员发送 |

接收邮件前需要先绑定邮箱。如果出现「通知设置加载失败，重试」，点击该按钮重新读取设置后再调整。

## 设置批量下载的存放位置

「存储设置」只为你担任组织所有者或组织管理员的组织显示。管理多个组织时，先在该区域上方选择要设置的组织。

1. 在「存放位置」下点击「选择文件夹」；已经设置过时，按钮显示当前文件夹名。
2. 在浏览器弹出的窗口中选择本地文件夹，并按提示授权读写。
3. 确认按钮显示选中的文件夹名，再到[组织管理的文件页面](/docs/organization#查看与下载提交文件)发起批量下载。

每个组织分别记住这台浏览器的存放位置。更换电脑、浏览器或清除浏览器数据后，需要重新选择；要更换目录，点击当前文件夹名重新选择即可。

如果提示浏览器不能选择下载文件夹，请使用桌面版 Chrome 或 Edge。下载时若再次出现文件夹授权请求，按提示确认。每次批量下载都会在所选文件夹中新建时间目录，不覆盖已有下载批次。
