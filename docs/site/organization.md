顶部「**管理**」入口仅对当前组织的**组织所有者**和**组织管理员**开放。操作前请先确认左上角已切到目标组织。

## 角色权限一览

| 角色           | 权限范围                                                                |
| :------------- | :---------------------------------------------------------------------- |
| **组员**       | 浏览企划，接取、提交或放弃自己的任务                                    |
| **组织管理员** | 维护组织设置、成员、申请、邀请码、企划类型、标签、原子任务、模板与文件  |
| **组织所有者** | 拥有管理员全部能力，且**唯一有权调整成员角色**（每个组织仅 1 名所有者） |

## 邀请成员与审核申请

在「**管理 → 邀请码**」点击「**生成邀请码**」，可按需设置可用次数与有效期；停止招募时可随时失效。

![邀请码管理：生成、查看使用次数与失效邀请码](/docs/screenshots/org-invites.webp)

- **新用户**：凭邀请码注册后，管理员需在「**入组申请**」中点击通过，账号才会生效。
- **已有账号**：直接从左上角组织菜单填邀请码即可加入，无需审核。

## 维护基础配置

| 菜单         | 用途                                                               |
| :----------- | :----------------------------------------------------------------- |
| **组织设置** | 修改组织名称、头像与简介（最多 500 字）                            |
| **成员**     | 启用/停用成员、查看各工种提交统计；所有者可升降管理员              |
| **企划类型** | 维护作品分类与排序（已被企划使用的类型不可直接删除）               |
| **标签**     | 维护预制标签名与颜色（删除不影响已保存的企划标签）                 |
| **企划**     | 启停企划；管理员在项目详情中还支持**分配、取消接取、代提交与打回** |

## 处理删除请求

「**删除请求**」汇集了需要审核的企划/项目删除申请（含项目或提交记录的资源）。查看原因后选择通过或拒绝。

## 查看与批量下载文件

在「**管理 → 文件**」可按企划类型、企划、项目或任务浏览全部提交文件（含历史版本），支持预览、删除与批量下载。

![组织文件管理：按作品与任务维度筛选、预览和批量下载提交文件](/docs/screenshots/org-files.webp)

> **批量下载前提**：首次使用前，请先在[个人设置 → 存储设置](/docs/settings#存储设置与-openapi-密钥)选择本地存放文件夹（建议使用桌面版 Chrome / Edge）。每次批量下载会自动新建时间目录，不覆盖旧批次。
