## 先认识三个概念

**企划**是一个作品或协作主题的容器，例如某部漫画。**项目**是企划下的一次具体工作，例如第一话。**工作流**规定这个项目要经过哪些任务，例如翻译、校对、嵌字。

一个企划可以有多个项目，每个项目都有自己的任务流和进度。完成一个任务后，流程按组织配置的阶段继续推进。

## 按你的角色阅读
