## 30 秒认识三个概念

| 概念       | 是什么                   | 举例                      |
| :--------- | :----------------------- | :------------------------ |
| **企划**   | 一部作品或协作主题的容器 | 《银色的结晶》            |
| **项目**   | 企划下的一次具体交付     | 第一章 / 第一话           |
| **工作流** | 项目要经过的协作步骤     | 翻译 → 校对 → 嵌字 → 发布 |
