title: 接取与提交任务
icon: ClipboardCheck
---

任务是项目中的具体分工（如翻译、校对、嵌字）。整体流程只有四步：**大厅找任务 → 接取 → 工坊处理 → 提交成果**。

## 1. 在任务大厅找任务并接取

打开<a href="/dashboard/task-plaza" target="_self">任务大厅</a>，按企划类型、任务类型或等待时长筛选，展开作品即可直接点击「**接取**」：

- **全部阶段**：可提前认领后续阶段任务（需等前置阶段完成后才能提交）。
- **当前阶段**：仅看现在就能动工的任务。

![任务大厅展开作品后，可查看当前阶段与后续阶段任务并一键接取](/docs/screenshots/task-claim.webp)

| 状态       | 含义         | 可执行操作                               |
| :--------- | :----------- | :--------------------------------------- |
| **待接取** | 暂无认领人   | 接取                                     |
| **进行中** | 已被成员认领 | 提交、暂存或放弃（提交需前置阶段已完成） |
| **已完成** | 已有有效提交 | 查看成果与历史版本                       |

## 2. 在工坊处理待办

接取的任务会汇总到<a href="/dashboard/workshop" target="_self">工坊</a>，自动分为两栏：

- **可提交**：前置阶段已完成，点进去就能提交。
- **等待中**：正在等前置任务完成，卡片会提示具体在等哪一步。

![工坊页面：上方分「可提交」「等待中」展示个人待办，下方列出参与的企划](/docs/screenshots/workshop.webp)

> **并行与命名规则**：同一阶段有多个并行任务时，需全部完成才解锁下一阶段。「翻译 · 2/3」表示该并行组的第 2 个槽位；同名任务出现在不同阶段时会标注「第 N 步」。

## 3. 提交成果与暂存

1. 在工坊或项目详情中打开自己可提交的任务。
2. 按表单填写说明、上传附件，等待上传完成后点击「**提交**」。
3. 未写完时可先点「**暂存**」（仅自己可见），下次继续提交。

## 4. 放弃任务或被打回

- **无法继续时**：在任务详情点击「**放弃**」，任务立即回到「待接取」（等待前置期间也可随时放弃）。
- **任务被打回**：查看通知里的打回意见，在原任务中重新提交；旧提交会保留在版本历史中。

更多状态与权限说明见[常见问题](/docs/faq)。
