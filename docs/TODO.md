# 待办事项

## 原子任务 Lucide 图标

**状态：已完成（2026-10-10）**

原子任务只保存可选的 Lucide 图标标识 `icon`。创建请求和列表响应都使用该字段，模板节点、工坊节点和任务实例节点只返回可选的 `baseTaskIcon`。后端不维护图标白名单，也不再保存或返回 `iconFileId`、`iconName`、`iconUrl`、`baseTaskIconName`、`baseTaskIconUrl`。

### 前端接入

1. “工坊 / 原子任务”的创建表单提供完整 Lucide 图标选择器，保存的是图标字典键，例如 `Languages`、`Camera`。
2. 创建原子任务时只提交可选的 `icon`。
3. 任务管理卡片、流程编辑器、流程模板卡片和任务流都通过共享解析函数展示图标。
4. 有效图标标识优先于任务名称。未填写、空字符串或未知标识时，按名称匹配：翻译/校对、审核/编辑、发布、创建，其余使用 Star。`constructor`、`toString` 等原型键按未知标识处理。

图标独立于任务提交字段。提交字段使用结构化 `submitFields`。

## 原子任务删除

**状态：已完成（2026-10-10）**

组织管理端通过 `DELETE /orgadmin/task/base/{taskId}` 逻辑删除原子任务。任务卡片在二次确认后调用该接口；确认内容包含任务名称，并说明删除不可恢复。

`refCount > 0` 时禁用删除入口，并提示改为禁用。后端仍会拒绝被任务模板或项目任务节点引用的删除，前端保留请求失败的全局错误提示，不把前端计数当作唯一校验。删除成功后提示“原子任务已删除”；若删除的是当前页最后一项且页码大于 1，则回退一页，否则刷新当前列表。
